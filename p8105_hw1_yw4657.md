# Problem 2

``` r
set.seed(123)

sample = rnorm(10)

logical_var = sample > 0

character_var = c("A", "B", "C", "D", "E",
                  "F", "G", "H", "I", "J")

factor_var = factor(c("low", "medium", "high", "low", "medium",
                      "high", "low", "medium", "high", "low"))

df = data.frame(
  sample = sample,
  logical_var = logical_var,
  character_var = character_var,
  factor_var = factor_var
)
```

``` r
mean(pull(df, sample))
```

    ## [1] 0.07462564

``` r
mean(pull(df, logical_var))
```

    ## [1] 0.5

``` r
mean(pull(df, character_var))
```

    ## [1] NA

``` r
mean(pull(df, factor_var))
```

    ## [1] NA

The mean can be calculated for the numeric and logical variables, but
not for the character or factor variables. The logical variable can be
averaged because R treats `TRUE` as 1 and `FALSE` as 0. Character values
cannot be averaged because they are not numeric. Although factors have
internal numeric codes, a factor itself is not a numeric variable, so
its mean cannot be calculated directly.

``` r
as.numeric(pull(df, logical_var))
as.numeric(pull(df, character_var))
as.numeric(pull(df, factor_var))
```

Converting the logical variable to numeric produces 1s and 0s, which
explains why its mean can be calculated. Converting the character
variable produces `NA` values because the character values are not
numeric. Converting the factor produces its internal numeric level codes
rather than the original factor labels. These results help explain why
the numeric and logical variables can be averaged directly, whereas the
character and factor variables cannot.
